# FrameHome

Independent Godot/OpenXR application for Steam Frame. GPL-3.0-or-later.
Work here only; QuestHome is the read-only origin of the imported art snapshot.
Runtime is Godot 4.6.1, native Linux ARM64, with desktop Windows/Linux previews.
Keep generated builds, editor/template downloads, user saves and cover art out of Git.
Do not use Meta Spatial SDK or assume Horizon OS services exist on SteamOS.
Use explicit per-file staging. Do not alter Steam's system Home or install autostart
without an explicit user request. Device deployment requires a paired development host.
Physical VR behavior must be reported separately from successful asset import/export.
